# 用户手册 (User Manual)

## 1. 快速开始
欢迎使用“未来图书馆”小说阅读系统。本系统提供简洁高效的纯净阅读体验。

## 2. 功能操作指南

### 2.1 发现小说
- **浏览**: 在首页你可以看到当前系统推荐的热门小说。
- **搜索**: 使用顶部的搜索框，输入小说名称或关键词即可快速定位书籍。

### 2.2 查看书籍详情
- 点击感兴趣的小说卡片，进入详情页面。
- 你可以查看书籍的完整简介及更新章节数。
- 点击“开始阅读”将跳转到第一章，或在目录中点击特定章节进入。

### 2.3 沉浸阅读
- 阅读页采用了护眼的暖色纸质风格。
- 底部提供“上一章 / 返回目录 / 下一章”导航；上一章与下一章始终按照作者保存的最新章节顺序跳转，第一章/末章的对应按钮自动禁用。
- 点击“返回目录”可以随时回到该书的详情目录页。

### 2.4 章节排序（作者）
- 在书籍详情页“章节目录”右上角点击“排序管理”，进入排序模式。
- 进入前系统会弹窗提示：**调整顺序将影响所有读者的目录展示与“上一章 / 下一章”阅读路径**，确认后才开始调整。
- 支持两种移动方式：
  - **拖拽排序**：直接按住章节卡片拖动到目标位置。
  - **按钮移动**：使用每行右侧的 ↑ / ↓ 逐章移动，或一键移到最前 / 最后。适合把序章移到开头、把番外移到结尾、修正错位章节。
- 调整期间仅为本地草稿，不影响线上读者；点击“保存顺序”成功后目录与阅读导航才会一起更新。
- 若保存失败，页面会自动恢复为服务器上的原顺序并提示错误，不会留下“只更新了一半”的章节列表；点击“撤销更改”可随时放弃本地草稿。

## 3. 常见问题 (FAQ)

**Q: 为什么系统是浅色的？**
A: 为了提供更好的可读性，系统近期升级到了全新的浅色主题。

**Q: 我可以在移动端使用吗？**
A: 是的，系统完全适配移动端浏览器，你可以通过手机进行阅读。

**Q: 数据会丢失吗？**
A: 当前版本为内存存储演示版，重启容器后台数据会重置回初始种子数据。
