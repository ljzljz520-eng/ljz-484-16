## 3. 接口测试 (API Testing)
使用 Swagger 进行接口验证：
- `GET /api/novels`: 返回 200，JSON 包含分页数据。
- `GET /api/novels/1`: 返回书籍详情及章节数据。
- `PUT /api/novels/1/chapters/order`: 合法列表返回 200 及新顺序；缺章节/重复/混入他书章节返回 400，且目录保持原顺序（原子性）；小说不存在返回 404。
- `GET /api/chapters/1`: 返回正文及 `prevChapterId` / `nextChapterId`，重排后导航自动跟随。

## 3.1 自动化测试
后端包含 13 个自动化用例（`mvn test`，全部通过）：
- `DataRepositoryTest`（6 个）：重排编号、各类非法输入失败且原顺序不变、前后章导航跟随重排。
- `NovelControllerTest`（7 个）：重排 API 成功/400/404、失败后目录无半更新、章节详情导航字段。
