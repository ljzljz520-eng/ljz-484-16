## 3. 接口测试 (API Testing)
使用 Swagger 进行接口验证：
- `GET /api/novels`: 返回 200，JSON 包含分页数据。
- `GET /api/novels/1`: 返回书籍详情及章节数据。
- `GET /api/chapters/1`: 正确返回正文字符串。
- `PUT /api/novels/1/chapters/reorder`: 传入完整章节 ID 新顺序后返回 200 及重排后的章节；章节数不符、ID 重复、包含其他书章节时返回 400 且顺序保持不变。
- `GET /api/chapters/1/navigation`: 返回当前章节及上一章/下一章信息，排序后结果随之变化。

## 3.1 单元测试
- `DataRepositoryReorderTest` 覆盖：重排生效且 orderNo 连续、目录顺序一致、上一章/下一章导航跟随新序、首末章边界、非法入参（数量不符 / 重复 / 外书 ID）拒绝且原顺序不变。
